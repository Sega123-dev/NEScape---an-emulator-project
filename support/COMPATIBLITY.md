# NEScape emulator official compatibility list

On this page,I will cover the games that are supported by this emulator.Every game,either commercial or homebrew will be divided into sections based on a base mapper they use for memory.By "supported",I will include these specificications:

- Game looks decent enough that visual bugs do not interrupt the gameplay
- Audio is close enough to associate it to the refering game that user is playing
- Controls work(If you are on version 0.5.0,2 player mode and Zapper are not supported on that version)
- You are able to play the game from start to finish without major setbacks

  **NOTE: ** For testing,the US/EU/JP/World versions of the NES ROMs will be used,format iNES 1.0/2.0 only. Homebrew ROMs are also going to be used for testing,but only the ones that actually are supported based on mapper coverage.This list will cover 200+ games (150+ most popular commercial titles),but it is not limited to only this list.The list will be expanded into database and probably will be not updated in this markdown file.
